# TrustPay Web Design Direction

## Visual System

- Use a dark charcoal base, not pure black for every surface.
- Use orange as the main action color.
- Use white buttons only as secondary contrast on dark hero sections.
- Keep cards compact with `rounded-lg`; avoid stacked cards inside cards.
- Use soft orange curved glow shapes for hero moments, then keep product sections quiet.

## UX Copy

- Write for users first: exchange, wallet funding, bills, withdrawals, receipts.
- Use short grade 5 sentences.
- Avoid admin words on public pages unless linking to the admin area.
- Show status words clearly: pending, successful, failed, reversed.
- Use `NGN` and `GHS` instead of unclear symbols in marketing copy.

## Safety

- Do not expose full bank account numbers in UI examples.
- Public pages should not imply TrustPay is a bank.
- Admin pages must show review context, audit needs, and safe support workflows.
- Financial actions must stay clear about status and confirmation.
